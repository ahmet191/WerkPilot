# Contributing

WerkPilot is a **proprietary project** (see [LICENSE](LICENSE)) published for
evaluation and portfolio purposes. External code contributions are not being
accepted at this time, and pull requests may be closed without review.

You are welcome to:

- **Report security issues** privately — see [SECURITY.md](SECURITY.md).
- **Open an issue** to report a bug or ask a question.

If you are interested in using or licensing WerkPilot, contact the maintainer at
**ahmetcemaleddin@gmail.com**.
